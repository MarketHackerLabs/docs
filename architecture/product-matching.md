# Соответствие товаров маркетплейсов

## Назначение

Модуль `product_matching` хранит общую для организации карту внутренних товаров и артикулов Wildberries и Ozon. Карта не зависит от подключённых кабинетов и доступна будущим продуктовым модулям.

## Данные

- `product_matching_products` — внутренний SKU и необязательное название товара.
- `product_matching_listings` — артикул площадки и для Wildberries опциональный `catalog_id` (`nm_id`).

Внутренний SKU уникален в организации. Артикул площадки уникален в пределах организации и маркетплейса. Обе таблицы защищены RLS по `org_id`.

`stock_control` связывает физический остаток с товаром, а снимок выставленного остатка — с листингом и кабинетом.

## Изображения

Обложки показываются только для Wildberries. URL **не хранится**: при чтении доски он собирается из `catalog_id` (`nm_id`) через basket CDN:

`https://{basket-host}/vol{nm//100000}/part{nm//1000}/{nm}/images/big/1.webp`

Если в карте лежит `chrtId`, `catalog_id` заполняется при синхронизации кабинета из content cards (`chrtId` → `nmID`). Картинки Ozon в v1 не используются.

## REST API

Префикс:

`/api/v1/organizations/{org_id}/product-matching`

| Метод | Путь | Назначение |
|-------|------|------------|
| `POST` | `/import` | Импортировать CSV или Excel с колонками SKU, артикул WB, артикул Ozon |
| `GET` | `/template` | Скачать шаблон CSV |

Обе операции доступны владельцу организации. Наличие фичи `stock_control` не требуется.
